# Brickly Landing Page – Screenshots

Umieść screenshoty aplikacji w tym folderze, aby pojawiły się w galerii.

## Oczekiwane nazwy plików (zgodne z `Gallery.tsx`):

| Plik | Opis modułu |
|------|-------------|
| `dashboard.png` | Panel główny |
| `projects.png` | Lista projektów |
| `project-details.png` | Szczegóły projektu |
| `cost-estimate.png` | Kosztorys projektu |
| `cost-template.png` | Szablony kosztorysów |
| `schedule.png` | Harmonogram prac |
| `files.png` | Repozytorium plików |
| `chat.png` | Komunikator |
| `members.png` | Zarządzanie członkami |
| `tenants.png` | Zarządzanie organizacjami |

## Uwagi
- Format: PNG lub JPG
- Zalecany rozmiar: min. 1280×800 px (proporcje 16:10)
- Można też przeciągnąć i upuścić pliki bezpośrednio na galerię w przeglądarce
