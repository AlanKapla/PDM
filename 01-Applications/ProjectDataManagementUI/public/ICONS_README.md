# PWA Icons

Aby aplikacja działała jako pełnoprawna PWA, musisz dodać ikony:

1. **icon-192.png** - ikona 192x192px
2. **icon-512.png** - ikona 512x512px

Umieść je w folderze `public/`

## Generowanie ikon

Możesz użyć narzędzi online do generowania ikon PWA:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

## Format
- PNG format
- Transparent background (opcjonalnie)
- Square dimensions (192x192 i 512x512)
