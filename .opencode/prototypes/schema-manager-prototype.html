3. API Endpoints (definicja dla backendu)

Method Endpoint Opis
GET /api/tenants/{tid}/projects/{pid}/cost-estimate/{eid} Zwraca CostEstimateDetailsWeb ze schematem (schema zamiast templateStructure)
POST /api/tenants/{tid}/projects/{pid}/cost-estimate/{eid}/schema/fields Dodaje nowe pole do schematu. Body: { label, fieldType, fieldScope, order }
PUT /api/tenants/{tid}/projects/{pid}/cost-estimate/{eid}/schema/fields/{fid} Aktualizuje pole (label, isVisible, order). Body: { label?, isVisible?, order? }
DELETE /api/tenants/{tid}/projects/{pid}/cost-estimate/{eid}/schema/fields/{fid} Usuwa pole (tylko dla isUserDefined == true). Soft delete.
POST /api/tenants/{tid}/projects/{pid}/cost-estimate/{eid}/schema/fields/reorder Zmienia kolejność pól. Body: { fieldIds: Guid[] }
GET /api/tenants/{tid}/projects/{pid}/cost-estimate/{eid}/export/pdf Eksportuje kosztorys do PDF (fancy design). Response: Binary PDF (download).
